Use this guide to migrate from UC Local APEX Dev 26.1 to 26.2. This release upgrades Oracle Database and ORDS in place.

If you are installing for the first time, use [Getting Started](/products/uc-local-apex-dev/docs/getting-started/) instead.

## Changes

This section lists the main changes.

| Name | Description |
| --- | --- |
| Oracle Database | Upgrades from `23.26.0.0` to `23.26.1.0`. Datafiles are compatible. |
| ORDS | Upgrades from `25.4` to `26.1`. |
| `drop-user.sh` | Removes the matching SQLcl connection and comments credentials in `.env`. |
| `create-user.sh` | Adds grants for Advanced Queuing, JavaScript, and catalog privileges. |
| `unexpire-accounts.sh` | Fixes workspace account expiration handling with `apex_util.set_security_group_id`. |
| `after-first-db-start.sh` | Sets maximum application backups and improves non-interactive use over SSH. |
| `install-dbms-cloud.sh` and `create-datapump-directory.sh` | Improve non-interactive use over SSH. |
| `drop_all.sql` | Drops queue tables and avoids object types that caused errors. |
| Compose support | Supports both `docker-compose` and `docker compose`. |

## Before You Begin

This section confirms that you are ready to migrate.

> **Important**
> Start from release 26.1. If you are on an older release, run the earlier migrations first.

> **Caution**
> Back up your database before you upgrade. If you created schemas or workspaces outside this project, back them up manually.

1. Confirm that the database is running.

   ```bash
   docker ps
   ```

2. If the database is not running, start it.

   ```bash
   ./local-26ai.sh start
   ```

## Migrate

This section upgrades the project files and starts the updated containers.

1. Back up schemas and APEX workspaces created by this project.

   ```bash
   ./local-26ai.sh backup-all
   ```

2. Confirm that backup files exist in `backups/export`.

3. Stop the containers.

   ```bash
   ./local-26ai.sh stop
   ```

4. Switch to the `26-2` branch.

   ```bash
   git fetch
   git checkout 26-2
   ```

5. Make the scripts executable.

   ```bash
   chmod +x ./local-26ai.sh ./setup.sh ./scripts/*.sh
   ```

6. Start the containers.

   ```bash
   ./local-26ai.sh start
   ```

7. Watch the database logs until the database upgrade finishes.

   ```bash
   docker logs -f local-26ai
   ```

8. Watch the ORDS logs until ORDS finishes its upgrade.

   ```bash
   docker logs -f local-26ai-ords
   ```

## Verify

This section confirms that APEX is available after the migration.

1. Open [http://localhost:8181/ords/apex](http://localhost:8181/ords/apex).
2. Confirm that the APEX sign-in page loads.
3. Sign in to a workspace and check your application data.

## Clean Up

This section removes old local images if you no longer need them.

1. List Docker images.

   ```bash
   docker image ls
   ```

2. Remove only images that you are sure you no longer need.

   ```bash
   docker image rm {image_name}
   ```
