Use this guide to migrate to UC Local APEX Dev 25.1. This release upgrades Oracle Database and Oracle APEX.

## Contents

## Changes

This section lists the main version changes.

| Name | Description |
| --- | --- |
| Oracle Database | Upgrades from `23.5` to `23.6`. |
| Oracle APEX | Upgrades from `24.1` to `24.2`. |

The database datafiles are compatible with this release. You still need a backup before you start.

## Before You Begin

This section helps you prepare for the migration.

> **Caution**
> Back up your database and the `oradata` volume before you upgrade. If you created schemas or workspaces outside this project, back them up manually.

1. Confirm that the database is running.

   ```bash
   docker ps
   ```

2. If the database is not running, start it.

   ```bash
   local-23ai.sh start
   ```

## Migrate

This section upgrades the project files and APEX installation.

1. Switch to the `25-1` branch.

   ```bash
   git checkout 25-1
   ```

2. Make the scripts executable.

   ```bash
   chmod +x ./local-23ai.sh ./setup.sh ./scripts/*.sh
   ```

3. Back up schemas and APEX workspaces created by this project.

   ```bash
   local-23ai.sh backup-all
   ```

4. Confirm that the backup files exist in `backups/export`.

5. Back up the `oradata` volume.

   > **Important**
   > Make sure `./backups/oradata` does not already exist before you copy the volume.

   ```bash
   source ./scripts/util/load_env.sh

   docker exec $CONTAINER_NAME bash -c "echo 'shutdown immediate;
   exit' | sqlplus / as sysdba && exit"

   docker cp $CONTAINER_NAME:/opt/oracle/oradata ./backups/oradata
   ```

6. Stop the containers.

   ```bash
   local-23ai.sh stop
   ```

7. Create `.env.ords` in the project root.

   ```bash
   echo "IGNORE_APEX=TRUE" > .env.ords
   ```

   ORDS does not include APEX 24.2 in this release, so this setting tells ORDS to ignore its bundled APEX files.

8. Start the containers.

   ```bash
   docker-compose up -d
   ```

9. Download and unzip the latest APEX release.

   ```bash
   curl -fLO https://download.oracle.com/otn_software/apex/apex-latest.zip
   unzip apex-latest.zip
   rm apex-latest.zip
   rm -rf ./META-INF || true
   ```

   If you use `wget`, run:

   ```bash
   wget https://download.oracle.com/otn_software/apex/apex-latest.zip
   ```

10. Install APEX.

    ```bash
    cd apex
    sql -name local-23ai-sys @apexins.sql SYSAUX SYSAUX TEMP /i/
    exit;
    ```

11. Copy the APEX images into the ORDS container.

    ```bash
    docker cp --archive ./images local-ords:/opt/oracle/apex/24.1.0/
    ```

## Verify APEX

This section confirms that APEX is usable after the migration.

1. Open APEX in your browser.
2. Sign in to a workspace.
3. If your browser shows an error that files are outdated, clear the browser cache and reload the page.
