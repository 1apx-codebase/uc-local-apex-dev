Use this guide to migrate from UC Local APEX Dev 25.1 to 25.2. This release upgrades Oracle Database and adds helper scripts.

## Contents

## Changes

This section lists the main changes.

| Name | Description |
| --- | --- |
| Oracle Database | Upgrades from `23.6` to `23.7`. |
| `local-23ai.sh disable-archive-logs` | Disables archive logging for local development. |
| `local-23ai.sh test-app-install ./path/to/my_app.sql` | Tests an APEX application install in a clean environment. |

The `test-app-install` script reports installed object counts, invalid object counts, and APEX object dependency scan results.

## Before You Begin

This section confirms that you are ready to migrate.

> **Important**
> Start from release 25.1. If you are on an older release, run the earlier migrations first.

> **Caution**
> Back up your database before you upgrade. If you created schemas or workspaces outside this project, back them up manually.

1. Confirm that the database is running.

   ```bash
   docker ps
   ```

2. If the database is not running, start it.

   ```bash
   docker-compose up -d
   ```

## Migrate

This section upgrades the project files and starts the updated containers.

1. Make the scripts executable.

   ```bash
   chmod +x ./local-23ai.sh ./setup.sh ./scripts/*.sh
   ```

2. Back up schemas and APEX workspaces created by this project.

   ```bash
   local-23ai.sh backup-all
   ```

3. Confirm that backup files exist in `backups/export`.

4. Optionally back up the `oradata` volume.

   > **Important**
   > Make sure `./backups/oradata` does not already exist before you copy the volume.

   ```bash
   source ./scripts/util/load_env.sh

   docker exec $CONTAINER_NAME bash -c "echo 'shutdown immediate;
   exit' | sqlplus / as sysdba && exit"

   docker cp $CONTAINER_NAME:/opt/oracle/oradata ./backups/oradata
   ```

5. Stop the containers.

   ```bash
   local-23ai.sh stop
   ```

6. Switch to the `25-2` branch.

   ```bash
   git fetch
   git checkout 25-2
   ```

7. Start the containers.

   ```bash
   docker-compose up -d
   ```

## Clean Up

This section removes old local images if you no longer need them.

1. List Docker images.

   ```bash
   docker image ls
   ```

2. Remove only images that you are sure you no longer need.

   ```bash
   docker image rm {image_name}
   ```
