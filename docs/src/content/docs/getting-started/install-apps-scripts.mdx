Use this guide to test whether an APEX application export or SQL script installs cleanly. The scripts use the `UC_TESTINSTALL_1` schema and workspace.

## Contents

- [Test an APEX Application Install](#test-an-apex-application-install)
- [Test a SQL Script Install](#test-a-sql-script-install)
- [Command Options](#command-options)

<Aside type="caution" title="Test schema is cleared">
  These commands create or clear the `UC_TESTINSTALL_1` schema and workspace.
  Do not store data there that you need to keep.
</Aside>

## Test an APEX Application Install

This section installs an APEX application export into a clean test workspace and reports the result.

1. Run `test-app-install` with the path to the application export.

   ```bash
   local-26ai.sh test-app-install ./path/to/my_app.sql
   ```

2. Confirm the prompt.
3. Review the summary.

The summary includes:

- Object types and counts.
- Invalid database objects.
- APEX object dependency scan results.

To skip the confirmation prompt for automation, add `-y`.

```bash
local-26ai.sh test-app-install ./path/to/my_app.sql -y
```

3. Review the summary.

The summary includes:

- Object types and counts.
- Invalid database objects.

To skip the confirmation prompt for automation, add `-y`.

```bash
local-26ai.sh test-script-install ./path/to/sql_script.sql -y
```

## Command Options

This section lists the options used by both test commands.

| Name | Description | Required |
| --- | --- | --- |
| Application or script path | Path to the `.sql` file to install. | Yes |
| `-y` | Skips the confirmation prompt. Use only in automation or when you are sure the test schema can be cleared. | No |
