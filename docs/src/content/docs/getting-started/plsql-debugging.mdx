Use this guide to prepare PL/SQL debugging for schemas created by UC Local APEX Dev. PL/SQL is Oracle Database's procedural language for packages, procedures, and functions.

## Prerequisites

This section lists what you need before you start debugging.

| Name | Description |
| --- | --- |
| Created schema | A schema created with `local-26ai.sh create-user`. |
| VS Code SQL Developer extension | The VS Code extension used to connect and debug PL/SQL. |
| Debug build | Package, procedure, or function compiled for debugging. |
| Local IP address | The IP address that the database can use to call back to your machine. |

Schemas created by this project already include the database permissions needed for PL/SQL debugging.

## Find Your Local IP Address

This section shows commands for finding your local IP address.

| Name | Description |
| --- | --- |
| macOS | `ipconfig getifaddr en0` |
| Linux | `hostname -I \| awk '{print $1}'` |

## Start a Debug Session

This section gives the basic debugging flow.

1. Connect to your schema in the VS Code SQL Developer extension.
2. Compile the PL/SQL package, procedure, or function for debugging.
3. Set a breakpoint.
4. Start the debugger.
5. When prompted, enter your local IP address.
