Use this guide to export and import local development data. A backup helps you recover data before a migration, reset, schema clear, or schema drop.

Oracle Data Pump is Oracle's export and import tool for database objects and data. This project uses Data Pump for schema backups.

## Backup Output

This section explains where backup files are written.

| Name | Description |
| --- | --- |
| `./backups/export` | Default output folder for exported backup files. |
| `./backups/import` | Input folder used by import scripts. |

<Aside type="caution" title="Important: Manual backups">
  `backup-all` backs up users created with this project's `create-user` command.
  If you created schemas or workspaces another way, back them up manually.
</Aside>

## Back Up All Project Users

This section exports all users created by this project, including their APEX workspaces and applications.

1. Run `backup-all`.

   ```bash
   local-26ai.sh backup-all
   ```

2. Check `./backups/export` for the generated files.

## Back Up One Schema

This section exports one schema with its workspace and applications.

1. Run `backup-schema` with the schema name.

   ```bash
   local-26ai.sh backup-schema movies
   ```

2. Check `./backups/export` for the generated files.

## Import a Backup

This section imports a backup for one schema.

1. Confirm that the backup files are available to the import script.
2. Run `import-backup` with the schema name.

   ```bash
   local-26ai.sh import-backup movies
   ```

<Aside type="note" title="Current import scope">
  At the time this page was written, `import-backup` creates the user if needed
  and imports the Data Pump dump. You may need to import APEX workspaces and
  applications separately if the script does not handle them for your version.
</Aside>
