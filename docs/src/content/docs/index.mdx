UC Local APEX Dev creates a local Oracle APEX development environment on your computer. It runs Oracle Database Free, Oracle APEX, and Oracle REST Data Services (ORDS) in containers.

Oracle APEX is a low-code application development platform. ORDS is the web service that lets a browser access APEX and REST endpoints.

<Aside type="caution" title="Local development only">
  Do not use this project for production. It stores passwords in plain text and
  changes security settings to make local development faster.
</Aside>

## What the Project Includes

This section explains the parts that run in your local environment.

| Name | Description |
| --- | --- |
| Oracle Database Free | The local database used by APEX applications. |
| Oracle APEX | The application development platform. |
| ORDS | Oracle REST Data Services, the web service used by APEX and REST modules. |
| `local-26ai.sh` | A wrapper script for common tasks such as starting containers, creating users, and running backups. |
| `scripts/` | Individual Bash scripts used by the wrapper script. |
| `.env` | Local configuration and generated passwords. |

## What You Can Do

This section lists the main workflows that UC Local APEX Dev supports.

- Create an APEX workspace and matching database schema.
- Save database connections for SQLcl and the VS Code SQL Developer extension.
- Back up and restore schemas, APEX workspaces, APEX applications, and ORDS modules.
- Clear a schema and test an install again.
- Test an APEX application export or SQL script in a clean schema.
- Debug PL/SQL code from VS Code SQL Developer.
- Enable local HTTPS for ORDS by using self-signed certificates.

## Before You Install

This section helps you confirm that the project fits your local setup.

| Name | Description | Required |
| --- | --- | --- |
| Container runtime | Docker or Podman. | Yes |
| Compose command | `docker compose`, `docker-compose`, or `podman compose`. | Yes |
| SQLcl | Oracle SQLcl, available as the `sql` command in your shell. | Yes |
| Shell | A Bash-compatible shell. | Yes |
| Resources | At least 4 GB RAM, 3 CPUs, and 20 GB disk space are recommended for the container virtual machine. | Yes |
